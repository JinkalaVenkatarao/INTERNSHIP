How It Works

This project uses OpenCV Haar Cascade Classifiers — built-in algorithms that scan images for specific patterns. They were trained by Microsoft and come bundled with OpenCV, so zero downloads are needed. Each cascade specializes in one object type — faces, eyes, bodies, smiles, or cars.

What Can Be Detected

Face — frontal human faces
Eyes — eyes within face region
Full Body — complete standing person
Upper Body — torso and above
Smile — smiling expression
Car — vehicles in images

API Endpoints

POST /detect Upload image + run detection
GET /health Server health check
GET /stats Performance metrics
GET /detectors List available detectors

Best Images to Test

  • Clear frontal face photos (passport style) → best for Face detection
  • Group photos with multiple people → tests Face + Body
  • Smiling portrait photos → tests Smile detection
  • Traffic / parking lot photos → tests Car detection
  • Well-lit, high contrast images → always give better results
