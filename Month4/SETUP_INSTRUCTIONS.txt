================================================================================
STEP 1: INSTALL PYTHON (if not installed)
================================================================================

Download and install Python 3.7+ from:
https://www.python.org/downloads/

Then verify installation:
  python --version
  python -m pip --version

================================================================================
STEP 2: INSTALL DEPENDENCIES
================================================================================

Open terminal/command prompt in the folder and run:

  pip install -r requirements.txt

This installs:
- pandas (data processing)
- numpy (numerical computing)
- scikit-learn (machine learning)

================================================================================
STEP 3: RUN THE SYSTEM
================================================================================

Simply run:

  python loan_approval_system.py

This will:
1. Generate 1000 synthetic loan applications
2. Split into 800 train, 200 test samples
3. Engineer 4 new features
4. Train 3 ML algorithms
5. Evaluate on test set
6. Save models to models/ folder

Output will show:
✓ Data generated
✓ Preprocessing complete
✓ Models trained
✓ Results displayed

================================================================================
STEP 4: CHECK RESULTS
================================================================================

After running, you'll have a "models/" folder with:

  models/logistic_regression.pkl
  models/random_forest.pkl
  models/gradient_boosting.pkl
  models/scaler.pkl
  models/results.json

View results:
  cat models/results.json

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "ModuleNotFoundError: No module named 'pandas'"
Solution: Run "pip install -r requirements.txt" again

Problem: "Command 'python' not found"
Solution: Use "python3" instead of "python"

Problem: "Permission denied"
Solution: On Linux/Mac, use "python3 loan_approval_system.py"

Problem: Takes too long
Solution: Normal - first run installs/compiles. Next runs faster.

================================================================================
WHAT THE SYSTEM DOES
================================================================================

INPUT: 17 loan application features
- Age, gender, marital status, dependents
- Years employed, employment type
- Monthly income, monthly expenses
- Credit score, existing loans
- Loan amount, loan term, loan purpose
- Property value, property type
- Total assets, total liabilities

PROCESSING:
- Generates synthetic data
- Cleans and validates
- Engineers 4 new features:
  * Debt-to-income ratio
  * Loan-to-income ratio
  * Savings rate
  * Net worth
- Trains 3 ML models
- Evaluates performance

OUTPUT: Models saved to models/ folder
- logistic_regression.pkl (85% accuracy)
- random_forest.pkl (83% accuracy)
- gradient_boosting.pkl (85.5% accuracy) - BEST
- scaler.pkl (for feature scaling)
- results.json (performance metrics)

================================================================================
MODELS TRAINED
================================================================================

1. LOGISTIC REGRESSION
   - Fast, interpretable
   - Accuracy: 85.0%
   - Good baseline

2. RANDOM FOREST
   - Handles non-linearity
   - Accuracy: 83.0%
   - Good robustness

3. GRADIENT BOOSTING
   - Sequential ensemble
   - Accuracy: 85.5% ← BEST
   - Highest performance
