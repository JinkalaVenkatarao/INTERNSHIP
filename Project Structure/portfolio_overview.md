# Data Analysis Portfolio

This repository contains multiple end-to-end data analysis projects
demonstrating my skills in Python, data cleaning, exploratory data analysis,
and data visualization.

## Projects Included

### 1. Retail Sales Performance Analysis
This project analyzes retail sales transactions across different product
categories and regions.

Key Analysis:
- Monthly revenue and profit trends
- Category performance comparison
- Regional sales analysis
- Customer segmentation
- Discount impact on revenue

Tools Used:
Python, Pandas, NumPy, Matplotlib, Seaborn
